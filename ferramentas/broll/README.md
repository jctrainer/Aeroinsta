# Banco de B-roll Jota Fit

Clipes de apoio para cobrir a fala (A-roll). Grave na vertical (9:16), 5 a 10 s cada, celular apoiado, boa luz.
Nomeie: `tema_descricao_nn.mp4` e coloque na pasta do tema.

| Pasta | O que gravar |
|---|---|
| `treino/` | Você treinando (agachamento, búlgaro, supino, leg press, remada, terra), detalhes: mão na barra, anilha, pés |
| `alunas/` | Alunas treinando (**só com autorização escrita**), de costas ou sem rosto se preferirem |
| `execucao/` | Demonstração certo × errado de exercícios, câmera de lado |
| `app/` | Gravação de tela do app: treino do dia, dieta, histórico, chat |
| `comida/` | Prato montado, marmita, proteína, frutas, café da manhã |
| `rotina/` | Chegando na academia, preparando creatina, garrafa de água, tênis, relógio |
| `guarulhos/` | Ruas e pontos conhecidos de Guarulhos, fachada da academia (SEO local) |
| `bastidores/` | Risadas, conversa com alunas, momentos leves |
